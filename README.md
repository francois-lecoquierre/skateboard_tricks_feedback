# Skateboard Tricks Archive — feedback

This repository only collects reviews from the **test site** of Skateboard Tricks Archive: a
trick engine that names skateboard tricks, checks that they can be done and animates them in 3D.

## How to send your feedback

1. On the test site, review tricks on the **Benchmark** page or in the **Builder**: press
   *Validate* when a trick looks right, *Flag* and add a comment when something is off (the
   name, a rotation, the feet, the board, a grab…).
2. At the bottom of the page, press **Send on GitHub**: a new issue opens here, already filled
   with your report.
3. Check it and press **Submit new issue**. That's it, thank you!

A GitHub account is needed. Without one, press *Copy report* on the site and send the text to
whoever shared the site with you.

Issues are public: don't put personal information in your comments.
